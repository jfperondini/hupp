## Cria um projeto
npm create-next-app@latest

## Atualizar Dependências Locais:
npm update

## Verifique a versão atual do Next.js e suas dependências:
npm outdated

## Atualizar uma Dependência Específica
npm install nome-do-pacote@latest

## Atualizar o Next.js Globalmente (se aplicável)
npm install -g next@latest

## Atualize o react:
npm install react@latest react-dom@latest
